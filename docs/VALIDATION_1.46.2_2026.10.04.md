# 1.46.2 正式版合并核验

核验日期：2026-10-04。目标为正式版 Git 工作区，分支 `main`。本次依据用户授权，将已核验的 beta 音频设置、Esc、动画布局、世界等级规则、诊断异常处理、胖子英里激光及 Event 商店修订合并至正式版。提交、推送与远程发布由用户通过 GitHub Desktop 完成。

正式版已有的社区敌军、世界与关卡目录、独立场景和音乐、自有服务器预备接口继续保留。扩展世界选择界面默认关闭，初始目录保留空世界列表，网络客户端默认断开。

玩家等级规则为：世界 1 主线尚未全部通关时上限 Lv10；世界 1 全部主线通关后为 Lv20；世界 2 全部主线通关后，未持有对应军队核为 Lv35，持有对应核为 Lv40。每个世界的 50 个主线小关参与条件判断，红色限时关卡排除。已有高等级保存值保留，上限约束后续升级。原版阵营、基地强化与电脑单位配置沿用原有流程。

运行核心由正式版合并源码构建，SHA-256 为 `12293e55f50de159f3766a5685fc7931cac2f3c45f1ddc62af44f190ee8914d8`。候选名称为 `MSD_Core_1_46_2_Release_r6_20261004.dll`；正式版根运行入口使用 `build/MSD_Core.dll`。原生音频导出函数保留既有 ABI 名称，以维持宿主接口一致性。窗口、品牌配置及 EXE 文件属性使用 `1.46.2`。

本轮验证记录分别覆盖：

- 原生音频按钮、设置位置、开幕与结尾动画独立入口，以及设置、语言、地图、Event、战斗暂停与恢复的 Esc 路径。
- 音乐与音效独立输出的 12 段 PCM 采集，以及两个混合音频状态的保存重启。
- 407 个单位记录的 39,072 项等级条件检查，包含 fixture 中登记的第七款社区单位；100 个主线标记逐项缺失检查及 16 次原生强化。新增 fixture 单位仅用于验证。
- 十项 Event 的基地和地图商店显示、点击及返回，101 条商品的价格与购买上限，95 条原生发放。六条商品保留既有原生条件限制，鼠标取消、确认兑换及返回另行核验。
- 胖子英里在 Lv1、Lv20、Lv40 和四个距离条件下的 12 组原生激光、轨迹与伤害比较。
- 四种音频状态的 32 项菜单进入与返回检查、28 段菜单 PCM，以及遗留按钮状态注入检查。
- 诊断文件锁复现与恢复、215 帧窗口运行，以及第 160 帧异常注入后的线程结束和窗口释放顺序。
- 78 组双阵营武器行为及 1,218 组单位基础参数与 beta R4 已核验结果的逐项比较。
- 独立 PNG 场景、地形、音乐、社区敌军名单及实际波次出击，以及六款社区单位的敌军绝招启用和禁用策略。
- 正式版实际宿主和根目录核心配置在独立初始、满级测试存档下各完成 215 帧窗口启动、保存及重新加载检查。

菜单音频保持、诊断文件锁、线程清理、既有武器参数、实际发行入口及独立解压的最终结果见同名 JSON 和 `content_work/formal_1_46_2_beta_promotion_20261004/` 的对应报告。完整活动通关、长期运行、跨设备表现及公网联机继续保留专项核验范围。

发行包保留正式版初始原生种子与空社区拥有进度。beta 满级种子和测试启动入口未纳入发行清单。已有个人存档仅用于保护核对；所有自动验证写入独立目录。
