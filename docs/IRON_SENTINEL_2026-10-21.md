## 3. 实现

### 3.1 动作类与行为

- 行为库 v12 新增 `iron_slider`（基准 394，参数 `second_form` 指定内部单位）与 `iron_slider_second_form`（基准 395）。加载器按行为写入 `native_action`，以原生 `BattleAction_IronSlider` / `_2` 的虚表构造动作对象，并把第二形态的 UnitID 写入第一形态数据行的子单位字（+0xa4，与其他召唤类单位相同）。
- `src/community_content.cpp` 的 7 个钩子按 MSA 7.13 处理原生较早版本与 MSA 的差异（注释在源码第 688 行起）：
  1. `setAnimationID` 槽号换为 MSA 槽号（第一形态 8→9；第二形态 94–97→17 / 18 / 19 / 21；主炮导弹 52→14；巨型导弹 77→25、84→23；侧炮炮弹 43→共用爆炸 0xff03 + 槽 15）；
  2. 第一形态 `createObject` 按 MSA 编号建立弹体：侧炮 50 / 56 / 105 / 111 / 117 / 124 / 130 / 136（攻击组 30，即近战组），火箭 60，主炮导弹 64，残片 72 / 73；
  3. 第二形态 `createObject` 建立巨型导弹 24（攻击组 40）；
  4. `summonUnit` 召唤状态块 +0xa0 记录的子单位（原生写死 395）；
  5. 取消较早版本的 (0,30) 绘制偏移；
  6. 火箭弹体：重新进入画面后瞄准对方最前方单位的中心；
  7. 主炮导弹命中、失效或落地时生成本单位带攻击框的爆炸动作 103。
- 火箭的索敌（用户要求与攻击一致）：目标须在攻击距离边缘以内（单位 x ±（半宽 + 字 7 = 300））；边缘以内没有目标时落向边缘处的地面，不追击更远的单位；水平飞离发射点达到投射距离（字 26 = 600）时爆炸。
- 钩子只读写客体对象内存，无静态状态。

### 3.4 受击后退与绝招蓝光（R2）

- 受击后退：原生 `BattleAction_IronSlider` 的状态 80 只播放槽 12，后退来自槽 12 的 op7 [−700, 0, 50, 0]（经 `BattleObject::actionMoveX`，实测初速 −14、每 tick 加 1，共 118）；`knockback_distance_multiplier` 由核心既有钩子在状态 80 缩放该速度与加速度。单位位于本方后退界限附近时（LAB 1011 中约 x 470），原生不再向后推，后退距离相应变短或为 0。
- 绝招蓝光：原生 `BattleUnit::draw` 在 `isSpAttack()`（绝招可发动）时以 `BattleEffectRenderer::drawSpAttackEffect` 在单位脚点绘制蓝光，宽高取状态字 43 / 44 的两倍；两字为 0 时取当前帧第一个矩形的尺寸。原生 394 / 395 两字为 0，而本单位主槽不画帧（部件均为 op11 子层），蓝光画成脚点处约 31×31 的小光点。新增单位字段 `special_effect_size`（数据行 +0x344 / +0x348）写入 [380, 120]：按原版大型载具（286 等为 [160, 90]，蓝光约与本体等宽、高约为本体的 0.4–0.5）由本体图像范围（宽约 800、高约 476）换算。

### 3.5 菜单显示、头像、巨型导弹落点与形态转换（R4，核心 r74）

- 菜单显示：编队页（原生 `SC_Deck` 的 `CreateDeckObject`）以 `GetMenuUnitID` 建立精灵并播放动画 0，按原尺寸绘制，不另缩放；原生大型单位以菜单专用部件缩小（大杰 312 的槽 0–2 挂脚本 73–85，op19 50；原生 IRON SLIDER 394 挂脚本 100–108，op19 40）。父层 op19 不作用于子层。本单位菜单槽 0–2 改挂追加的 12 个部件副本（脚本 142–153，描述符脚本数 154），op19 40，偏移为 MSA 原值 × 8/15，下移量 3；与原生 IRON SLIDER 的菜单偏移相差 1–4。编队页中宽约为大杰的 1.1 倍（50% 时约 1.4 倍）。战斗槽不变。
- 头像：原生头像为透明底剪影，矩形按锚点画在 50×50 的格中，选单位格内框为 (5,5)–(45,45)；40×40、锚点 (−5,−5) 恰好填满内框，46 高、锚点 (−5,1) 的头像向上越出 6 像素（原生 18 项为 46×46）。MSA 头像图集 `unit_icon_02.obme` 中本单位为 (295,644) 46×46、IRON CAB 为 (480,647) 42×46，左列与底行各有 40 像素不透明（内框在格的左下）。`msa_icons.py` 把两格原样写入 `unit_icon_02.obm` 的 (1650,768)、(1600,768)，`icon` 为 46×46 / 42×46、锚点 [−5, 1]；此前为 1:1 裁出的 40×40（锚点 [−5, −5]）。原格副本在 `artwork/iron_sentinel_msa_20261021/source/`。
- 巨型导弹落点：原生与 MSA 的 `BulletAction_IronSlider_Atack_2::update` 在导弹升出舞台上沿时按对方最前方单位的 x 与斜落角度定一次起点，之后不再修正；步兵等单位在约 45 tick 的下落中继续前进，导弹落在其后方，靠爆炸范围命中。核心钩子 10 在状态 40 每 tick 按对方最前方单位当前的 x 重设水平速度（竖直速度不变，水平速度不超过竖直速度），使导弹在该单位所在处落地。
- 形态转换的闪现：原生在召唤第二形态的同一次更新中移除第一形态，第二形态要到下一帧才更新、才有动作，这一帧画面中没有车体。钩子 9 改为预约状态 140（原生：动画结束即移除），第一形态在召唤的帧仍显示损毁动作的最后一帧，下一帧移除，第二形态同帧开始绘制。
- 据点被毁：本方据点被毁时原生令第一形态进入状态 100（生命仍大于 0），损毁动作结束后召唤第二形态；战斗已结束，第二形态停在状态 0、不绘制，看起来直接消失。钩子 8 在召唤后判断第一形态生命大于 0 或本方据点生命为 0 时，令第二形态立即预约状态 100，播放其损毁动作（槽 21）后移除。`summonUnit` 在本方单位数达到上限时不召唤（原生与 MSA 相同），未改。
